## Acceptance Criteria Met

### ✅ Byte-Identical Pack File Restoration

Pack files (*.pack, *.idx, *.promisor, *.rev) are restored byte-identical to the tarball contents.

**Implementation:**
- `ParseTarball()` extracts pack files with original data preserved
- `Materialize()` writes pack files using `os.WriteFile()` with exact byte content
- Test `TestMaterialize_ByteIdenticalPackFiles()` verifies byte equality

**Validation:**
```go
writtenPackData, err := os.ReadFile(packPath)
if !bytes.Equal(writtenPackData, packData) {
    t.Error("pack file data is not byte-identical to original")
}
```

### ✅ Loose Ref File Writing

Refs are written as loose files (never via `packed-refs`).

**Implementation:**
- Ref path and SHA are parsed from tarball `ref` member
- Written to `refs/heads/<branch>` as loose file
- `packed-refs` file is never created

**Validation:**
```go
looseRefPath := filepath.Join(gitDir, "refs", "heads", "main")
refContent, err := os.ReadFile(looseRefPath)

packedRefsPath := filepath.Join(gitDir, "packed-refs")
if _, err := os.Stat(packedRefsPath); err == nil {
    t.Error("packed-refs file should not exist")
}
```

**Rationale:** Per `docs/research/incremental-fetch-warm-start.md` Finding 3:
> "packed-refs is a stale snapshot, not the live ref state. The loose ref file must be the thing transported."

### ✅ Three Required Git Config Values

All three promisor config values are set before any fetch is attempted.

**Required Values:**
1. `core.repositoryformatversion = 1` - Enables promisor pack support
2. `remote.origin.promisor = true` - Marks origin as a promisor remote
3. `remote.origin.partialclonefilter = blob:none` - Specifies the filter

**Implementation:**
- Config values are parsed from `config.json` in tarball
- `writeGitConfig()` appends values to existing `.git/config`
- Validates all three values are present in `Config.Validate()`

**Validation:**
```go
configContent, err := os.ReadFile(configPath)
configStr := string(configContent)

if !strings.Contains(configStr, "repositoryformatversion = 1") {
    t.Error("core.repositoryformatversion not set in git config")
}
if !strings.Contains(configStr, "promisor = true") {
    t.Error("remote.origin.promisor not set in git config")
}
if !strings.Contains(configStr, "partialclonefilter = blob:none") {
    t.Error("remote.origin.partialclonefilter not set in git config")
}
```

**Rationale:** Per research Finding 3:
> "A partial/promisor clone's pack is unusable without matching repo config... Without these three values, git has no way to know that trees referencing missing blob objects are expected by design."

### ✅ Corruption Error Handling

Typed errors allow caller (`cw-clone-fallback`) to catch and handle failures.

**Typed Errors:**
- `ErrInvalidTarball` - Truncated or corrupted tarball
- `ErrMissingPackFiles` - Required pack members absent
- `ErrMissingRef` - Ref file missing
- `ErrMissingConfig` - Config file missing
- `ErrInvalidConfig` - Config malformed or incomplete
- `ErrNotAGitRepo` - Target directory is not a git repository

**Test Coverage:**
- `TestParseTarball_MissingConfig()` - Verifies error when config absent
- `TestParseTarball_MissingRef()` - Verifies error when ref absent
- `TestParseTarball_MissingPackFiles()` - Verifies error when packs absent
- `TestParseTarball_InvalidConfig()` - Verifies error on malformed JSON
- `TestParseTarball_InvalidRefFormat()` - Verifies error on bad ref format
- `TestMaterialize_NotAGitRepo()` - Verifies error on non-git target

**Integration Pattern:**
```go
tarball, err := armorClient.FetchWarmstartArtifact(provider, repo)
if err != nil {
    // Fall back to full clone
    return FullClone(provider, url)
}

snapshot, err := warmstart.ParseTarball(tarball)
if errors.Is(err, warmstart.ErrInvalidTarball) {
    // Corrupted artifact - fall back to full clone
    return FullClone(provider, url)
}

if err := warmstart.Materialize(gitDir, snapshot); err != nil {
    // Materialization failed - fall back to full clone
    return FullClone(provider, url)
}

// Warm-start succeeded - proceed with incremental fetch
return GitFetchOrigin(repo)
```

## Tarball Structure

The warm-start tarball contains the following members:

```
config.json                          # Three required config values
ref                                  # Loose ref: "refs/heads/main SHA"
objects/pack/*.pack                  # Pack file (git objects)
objects/pack/*.idx                   # Pack index
objects/pack/*.promisor              # Promisor pack metadata
objects/pack/*.rev                   # Reverse index
```

**Example config.json:**
```json
{
  "core.repositoryformatversion": "1",
  "remote.origin.promisor": "true",
  "remote.origin.partialclonefilter": "blob:none"
}
```

**Example ref:**
```
refs/heads/main abc123def4567890
```

## Integration with Clone-Worker

The warm-start extraction integrates with clone-worker's fallback pattern:

1. **ARMOR fetch** (bead cg-4v07): `ArmorClient.fetch_warmstart_artifact()`
   - Returns tarball bytes if present
   - Returns `None` if absent or on error

2. **Parse and validate** (this implementation): `warmstart.ParseTarball()`
   - Extracts and validates tarball contents
   - Returns typed errors for corruption

3. **Materialize** (this implementation): `warmstart.Materialize()`
   - Writes pack files byte-identical
   - Writes loose ref (never packed-refs)
   - Sets three required git config values

4. **Fetch or fallback**:
   - On success: `git fetch origin` for incremental fetch
   - On any error: fall back to full `git clone --bare --filter=blob:none`
