## Notes on NULL Values
While the schema allows NULL values for `github_login` and `resolved_at`, the frozen cache from claude-leaderboard contains no NULL values (all 349,425 rows have valid logins). However, the sample test file at `cmd/seed-author-login-cache/testdata/author_login_cache_sample.csv` includes NULL entries for testing purposes:
```
unknown.user1@example.com,NULL,2026-08-06T10:00:00.000000+00:00
unknown.user2@example.com,NULL,2026-08-06T10:05:00.000000+00:00
```

## Access Method
The table is accessed by `cmd/seed-author-login-cache/main.go` which:
1. Opens the SQLite database at `~/backups/claude-leaderboard/hot.db`
2. Reads all rows from `author_login_cache`
3. Filters out negative-cache entries (NULL/empty logins)
4. Ingests positive resolutions into PostgreSQL with `source='seed'`
