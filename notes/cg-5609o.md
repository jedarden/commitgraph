## Build Process

### Initial Build Issue
The initial build failed with compilation errors in `pkg/pg/identity.go`:
```
pkg/pg/identity.go:24:72: undefined: Rows
pkg/pg/identity.go:55:93: undefined: Rows
```

### Fix Applied
Added the missing `Rows` interface definition to `pkg/pg/identity.go`:
```go
// Rows is the interface returned by QueryContext (subset of sql.Rows).
type Rows interface {
	Next() bool
	Scan(dest ...interface{}) error
	Close() error
	Err() error
}
```

This interface was referenced in the `Executor` interface and `SQLExecutor.QueryContext()` method but was not defined.

### Build Success
